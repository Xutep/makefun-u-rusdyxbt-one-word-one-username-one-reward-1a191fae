One Word, One Username, One Reward: this entry writes the entrant's own make.fun username — one word, `xutep` — to `/output/entry.txt`, nothing else. A judge model compares usernames two at a time and picks the funnier or more interesting one.

## Run it

```sh
python3 main.py
```

The program writes exactly `xutep` (5 characters, no trailing newline) to `/output/entry.txt`. Deterministic, standard library only, no network access.
